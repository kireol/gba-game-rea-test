# Asset provenance

Every visual and audio element in Orbit Drop is generated by this repository's
own code at runtime. There are **no binary asset files** in the project and
**nothing downloaded at build or run time**.

## 1. Policy

The reference's assets may not be extracted, decoded, traced, sampled, converted
or embedded — not even as placeholders, and colour may not be picked from a
screenshot of the reference (project brief § 2.2). This file is the record that we
complied and how each asset was made.

The reference's own screenshots live in `docs/reverse-engineering/screenshots/`,
which is gitignored. They are behaviour documentation only: never shipped, never
imported by the application, never used as art source. `npm run report` guards the
naming side of the same rule.

## 3. Fonts

No third-party font is bundled, linked or fetched, so there are no OFL-style
licence obligations to record. If a typeface is ever added, add its licence file
under `licenses/` and a row here before merging.

## 4. Verification

* `src/tests/assets.test.ts` asserts the repo ships no binary media files, that
  `font5x7.ts` covers printable ASCII, and that the mode list is complete.
* `npm run report` (the name sweep) covers the naming half of the licence rules.
* `dist/` after a production build contains only HTML/JS/CSS generated by Vite —
  check with `find dist -type f ! -name '*.html' ! -name '*.js' ! -name '*.css'
! -name '*.svg'`.

## 5. Explicitly absent

No ROM, no emulator core, no decoded tile or map data, no palette copied as a set,
no sampled audio, no transcription of the reference's music, no font files, no
stock art packs, no generated-by-a-model imagery with unclear provenance.
